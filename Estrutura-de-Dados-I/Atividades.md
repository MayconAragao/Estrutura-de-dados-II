# 🔄 Estrutura de Dados: Implementação de Fila (Queue) em C

> Atividade prática de Estrutura de Dados focada na implementação e manipulação de uma **Fila de Números Inteiros** utilizando a linguagem C.

---

## 📌 Sobre a Atividade

Este projeto aborda o conceito de **Fila (FIFO - First In, First Out)**, onde o primeiro elemento a entrar é obrigatoriamente o primeiro a ser removido. 

A atividade consiste no desenvolvimento de funções em C para gerenciamento da fila, além de um menu interativo no terminal para o usuário realizar as operações em tempo real.

---

## 🛠️ Operações Implementadas

| Função | Descrição |
| :--- | :--- |
| `Inserir elemento (Enqueue)` | Adiciona um número inteiro no final da fila (com verificação de fila cheia). |
| `Remover elemento (Dequeue)` | Remove o elemento do início da fila (com verificação de fila vazia). |
| `Mostrar elementos` | Imprime todos os elementos presentes na fila na ordem atual. |
| `Limpar fila` | Esvazia todos os elementos armazenados na fila. |

---
